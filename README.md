# Forge

A self-hosted web GUI (Node.js + SQLite) for deploying, tracking, and
destroying Proxmox VMs — wrapping the existing Terraform/Ansible/phpIPAM
workflow with live status, per-step logs, and step-level retry.

Planning docs live in [`docs/`](./docs/00-overview.md) — start there.

Status: **planning phase**, no application code yet.
